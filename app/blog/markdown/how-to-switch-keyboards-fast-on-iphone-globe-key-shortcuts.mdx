The fastest way to switch keyboards on iPhone is to touch and hold the **Globe** or **Emoji** key while typing, then tap the keyboard you want. If you use only a few keyboards, tapping the key can cycle through them.

This works for Apple’s keyboard, emoji, additional language keyboards, and enabled third-party keyboards such as RewriteMate.

## The quick way to switch keyboards

While you are typing in any app:

1. Find the **Globe** key or **Emoji** key near the bottom of the keyboard.
2. Touch and hold it.
3. A list of enabled keyboards appears.
4. Tap the keyboard you want to use.

Apple’s current iPhone guide gives the same instruction: while typing, touch and hold the Emoji or Switch Keyboard key, then choose a keyboard from the list. [Apple’s keyboard guide](https://support.apple.com/en-gb/guide/iphone/iph73b71eb/26/ios/26) is the best source if the icon or menu looks different on your iPhone.

### Tap once to cycle through keyboards

If you have only two or three keyboards enabled, a single tap on the Globe key can be faster than opening the full list.

For example, you might cycle between:

1. Apple’s English keyboard
2. RewriteMate
3. Emoji

The exact order depends on the keyboard list in your iPhone settings. If you have many language and third-party keyboards enabled, touching and holding the key is usually more efficient because you can choose directly.

## Add a keyboard before trying to switch to it

A keyboard must be installed and enabled before it will appear in the Globe-key menu.

To add an Apple language keyboard:

1. Open **Settings**.
2. Tap **General**.
3. Tap **Keyboard**.
4. Tap **Keyboards**.
5. Tap **Add New Keyboard**.
6. Choose the language or keyboard layout you want.

To add a third-party keyboard such as RewriteMate:

![iPhone Add New Keyboards](https://res.cloudinary.com/diq74hzgo/image/upload/rewritemate/20260812_0246_5.jpg)

1. Install the keyboard app from the App Store.
2. Open **Settings > General > Keyboard > Keyboards**.
3. Tap **Add New Keyboard**.
4. Select the keyboard from the third-party keyboard section.
5. Complete any permission or setup steps the app explains.
6. Return to an app with a text field and use the Globe key to switch to it.

Apple notes that third-party keyboards can be added or removed from the keyboard settings area. [Its iPhone guide](https://support.apple.com/guide/iphone/change-the-default-apps-iphc57feab64/ios) also reflects the current iOS settings structure for keyboards.

## Put your most-used keyboards first

![iPhone Keyboards List](https://res.cloudinary.com/diq74hzgo/image/upload/rewritemate/20260812_0246_6.jpg)


Keyboard order matters when you use the one-tap Globe-key shortcut. Place the keyboards you use most near the top of the list so they are easier to reach.

To reorder keyboards:

1. Go to **Settings > General > Keyboard > Keyboards**.
2. Tap **Edit**.
3. Drag the reorder handle next to a keyboard.
4. Tap **Done**.

A simple setup might look like this:

| Keyboard | Why keep it enabled |
| --- | --- |
| Apple keyboard | Everyday typing and iPhone-specific features |
| RewriteMate | Rewriting, proofreading, and tone changes while typing |
| Emoji | Quick reactions and visual context |
| Second language keyboard | Multilingual messages and accurate character layouts |

If you rarely use a keyboard, consider removing it. Fewer enabled keyboards make the Globe-key cycle faster and reduce accidental switches.

## Why the Globe key may not appear

The Globe key is normally shown when iPhone has more than one keyboard available. If you only have one enabled keyboard, you may see an Emoji key instead, or no obvious keyboard switcher.

Try these fixes:

### Add a second keyboard

Open **Settings > General > Keyboard > Keyboards** and confirm that at least two keyboards are enabled. Adding Emoji or another language keyboard can make the switcher available.

### Look for the Emoji key

On newer iOS versions, the switcher may appear as an Emoji key instead of a Globe icon. Touch and hold it to see the available keyboards.

### Check the app’s text field

Some apps use secure text fields for passwords or other sensitive entries. iPhone may limit third-party keyboard use in those fields. Switch back to Apple’s keyboard when necessary.

### Restart the app

If the keyboard list does not update after you add a new keyboard, close and reopen the app where you are typing. If that does not help, restart your iPhone and check the keyboard list again.

### Confirm the third-party keyboard is enabled

Installing an app does not always enable its keyboard extension automatically. Return to **Settings > General > Keyboard > Keyboards** and make sure the keyboard appears in the active list.

## Globe key tips for multilingual typing

The Globe key is especially helpful if you write in more than one language.

Instead of changing your iPhone’s primary language every time you need a different keyboard, add the language keyboards you use and switch as needed. Apple says that when you add a keyboard for another language, that language is also added to the preferred language order, which can affect how apps and websites display text. [Apple’s keyboard settings documentation](https://support.apple.com/en-gb/guide/iphone/iph73b71eb/26/ios/26) explains this relationship.

For a smoother multilingual setup:

- Keep only the language layouts you actively use.
- Place your primary language first.
- Use touch-and-hold instead of repeated taps when choosing among several languages.
- Check which layout is active before typing names, addresses, or passwords.
- Add emoji only if you use it often enough to justify an extra stop in the cycle.

## How to switch keyboard languages faster

If you regularly move between two languages, the fastest approach is usually a single tap on the Globe key. If you use three or more keyboards, touch and hold the key and select the language by name.

For example:

- One tap can move from English to Vietnamese.
- Another tap can move to Emoji.
- A touch-and-hold lets you jump directly back to English without cycling through each keyboard.

This is useful for bilingual messages, translated drafts, and checking spelling in the correct language.

## Use the right keyboard for the task

No single keyboard is ideal for every job.

| Task | Keyboard approach |
| --- | --- |
| Quick reply | Use the keyboard you already have open |
| Emoji reaction | Switch to Emoji with the Globe or Emoji key |
| Bilingual message | Switch directly to the relevant language keyboard |
| Polish a work update | Switch to RewriteMate for a rewrite or grammar pass |
| Password entry | Use Apple’s keyboard if third-party keyboards are unavailable |
| Long message with multiple points | Draft first, then switch to the keyboard that helps you edit clearly |

The Globe key becomes more useful when you treat your keyboards as a small toolkit rather than a permanent default.

## Keep security and privacy in mind

Third-party keyboards may request permissions such as Full Access to provide certain features. Read the keyboard developer’s privacy information and permission explanation before enabling it.

You can review or remove a keyboard at any time:

1. Open **Settings > General > Keyboard > Keyboards**.
2. Tap **Edit**.
3. Tap the remove button next to the keyboard.
4. Confirm the removal.

You can also switch back to Apple’s keyboard instantly from the Globe-key menu. This is useful if you are entering sensitive information or simply prefer Apple’s keyboard for a particular task.

## Frequently asked questions

## How do I switch keyboards on iPhone without the Globe key?

Touch and hold the Emoji key if it appears in place of the Globe key. If neither option shows, check whether you have more than one keyboard enabled in **Settings > General > Keyboard > Keyboards**.

## Why does my iPhone keep switching keyboards?

This often happens when you have several keyboards enabled and accidentally tap the Globe key. Remove keyboards you do not use and reorder the remaining ones to make switching more predictable.

## Can I set a third-party keyboard as my default on iPhone?

You can enable a third-party keyboard and switch to it quickly with the Globe key. Some situations, including secure fields, may return you to Apple’s keyboard for security reasons.

## How do I add RewriteMate to my iPhone keyboard list?

Install RewriteMate, then go to **Settings > General > Keyboard > Keyboards > Add New Keyboard** and select it. Once it is enabled, touch and hold the Globe key while typing to choose it.

## What does the Globe key do on iPhone?

The Globe key lets you switch between enabled keyboards, including language keyboards, emoji, and third-party keyboards. Touch and hold it to select a keyboard from a list.

## Why can’t I use a third-party keyboard in a password field?

iPhone may restrict third-party keyboards in secure text fields to protect sensitive information. Use Apple’s built-in keyboard for those fields.

## Make keyboard switching part of your writing workflow

The Globe key is a small shortcut that can save time throughout the day. Add only the keyboards you actually use, put the important ones first, and touch and hold the key whenever you need to jump directly to a specific option.

Try RewriteMate when you want to refine a message without leaving the app where you are typing, then switch back whenever another keyboard better fits the task.
